# 표기 규칙

## 언제 쓰는가

- 날짜·금액·상태·계좌번호를 화면에 표시할 때
- 새 화면을 만들 때
- shadcn/ui 컴포넌트를 커스터마이즈할 때
- 안내·경고·거절 사유 문구를 쓸 때

## 왜 있는가

화면이 **12종**이다. 표기 규칙을 화면별 구현에 맡기면 **한 곳이 빠져도 알 수 없다.**

그래서 SRS §6.2는 전용 컴포넌트로 규칙을 강제한다. **타입에 위반 경로를 만들지 않는 방식**이다 — 코드 리뷰까지 갈 필요 없이 컴파일이 실패한다.

그리고 이 영역은 **규제가 직접 걸린다.** 문구 하나가 자본시장법·세무사법·금융소비자보호법 저촉이 될 수 있다.

---

## 공통 표기 컴포넌트 6종 — 반드시 사용

| 컴포넌트 | 강제하는 규칙 | 근거 |
| --- | --- | --- |
| `<BandDisplay>` | 밴드 두 값만 받으며 **단일 날짜 prop을 정의하지 않는다** | `SRS-FR-018`·`036` |
| `<LayerBadge>` | 확정(분단위 시각) / 추정(비단정 서술) 분기 | `SRS-FR-034`·`035` |
| `<SimulationLabel>` | 모의계산 라벨을 sticky로 고정 | `SRS-FR-082` |
| `<StatusLabel>` | enum → 한글 표시명. **원본 enum을 렌더하지 않는다** | `SRS-FR-047` |
| `<MoneyText>` | 원 단위 확정 금액. **비율 단독 표기 차단** | `SRS-FR-093` |
| `<MaskedAccount>` | 계좌번호 중간 4자리 마스킹 | `SRS-SEC-009` |

| ID | 규약 |
| --- | --- |
| `TEC-UI-001` | 완료일·해제일은 **반드시 `<BandDisplay>`**. 날짜 직접 렌더 금지 |
| `TEC-UI-002` | 상태 표시는 **반드시 `<StatusLabel>`** |
| `TEC-UI-003` | 금액 표시는 **반드시 `<MoneyText>`** |
| `TEC-UI-004` | 위 위반을 **ESLint 커스텀 룰 또는 리뷰 체크리스트**로 차단 |

## 밴드 — 이 제품의 정체성

**완료일을 단일 날짜로 표시하지 않는다. 예외 없다.**

```tsx
// components/domain/band-display.tsx
// 단일 날짜 prop이 타입에 존재하지 않는다 — 컴파일 단계에서 위반 차단
type BandDisplayProps = {
  endBandFrom: Date
  endBandTo: Date
  businessDaysMin: number
  businessDaysMax: number
  approximate?: boolean      // 폴백 ③④단계 시 "대략치입니다" 병기
}
```

**편의를 위해 `endDate` 같은 prop을 추가하면 이 설계가 무의미해진다.** 단일 날짜가 필요해 보이면 요구사항을 잘못 읽은 것이다.

> **왜 이렇게까지 하는가.** 특정 날짜를 약속하면 그 날짜에 못 끝났을 때 분쟁이 된다. 밴드는 "이 범위 안에서 끝난다"는 약속이고, 그게 실제로 지킬 수 있는 약속이다.

**폴백 ③④단계**에서는 `approximate`로 대략치임을 병기한다. 데이터 신선도가 낮을 때 확정처럼 보이면 안 된다.

---

## 상태 — 내부 enum을 노출하지 않는다

`TransferStatus` **12종**이 있다. 원본 문자열이 DOM에 나타나면 안 된다.

```tsx
<StatusLabel status={transfer.status} />   // ✅
<span>{transfer.status}</span>             // ❌ TEC-UI-002 위반
```

**12종 전부에 한글 표시명이 정의되어 있어야 한다.** 하나라도 빠지면 그 상태에서 화면이 깨지거나 개발자가 임의로 문구를 만든다.

---

## 금액 — 비율만 단독으로 보여주지 않는다

```tsx
<MoneyText value={taxAmount} />        // ✅ 465,960원
<span>{rate}%</span>                   // ❌ 비율 단독 (SRS-FR-093 위반)
```

비율을 보여줄 수는 있으나 **원 단위 확정 금액을 반드시 병기**한다. 고객이 실제로 내는 것은 금액이다.

## 접근성

| ID | 규약 |
| --- | --- |
| `TEC-UI-010` | 본문 **4.5:1** · 큰 텍스트 **3:1** 색 대비 |
| `TEC-UI-011` | 한글을 **어절 단위**로 줄바꿈 (`break-keep` 전역 기본값) |
| `TEC-UI-012` | **shadcn/ui 기본 ARIA 속성을 제거하지 않는다** |

**색만으로 정보를 구분하지 않는다.** 형태·문구를 병행한다. 확정/추정 배지가 색으로만 다르면 색각 이상에서 실패한다.

**포커스 표시를 미감 이유로 제거하지 않는다.**

## 문구 — 규제가 직접 걸린다

### 생성형 변환 금지

**안내·거절 사유·계산 근거는 전부 매핑표 기반이다.** 문구를 생성하지 않는다.

| 영역 | 저촉 법령 |
| --- | --- |
| 세무 관련 안내 | **세무사법 §2 4호** — 조세 상담·자문 |
| 종목 관련 문구 | **자본시장법 §6⑦** — 종목·수량·시기 지정 |
| 단정적 표현 | **금융소비자보호법 §21①** — 단정 금지 |

> **같은 사유 코드는 항상 같은 문구여야 한다.** 매번 다르면 고객이 다른 안내를 받게 된다. 그리고 생성 문구가 **"압류 대상자"** 같은 사람 규정 표현을 만들 위험이 있다.

### 피해야 하는 표현

| 하려는 것 | 판정 | 이유 |
| --- | :---: | --- |
| "절세" · "이득" · "유리합니다" | ❌ | 세무 자문으로 읽힌다 |
| "이 종목부터 매도하세요" | ❌ | 종목·시기 지정 (자본시장법) |
| "확실히" · "반드시 ~됩니다" | ❌ | 단정 (금소법) |
| 확인서 제출 **권유** | ❌ | 세무 자문 |
| 병목 종목을 "먼저 처리하세요"로 표현 | ❌ | 종목 지정으로 읽힘 |

**대신 이렇게 쓴다** — 사실을 제시하고 판단은 고객에게 남긴다. "제출 전 465,960원 / 제출 후 355,080원" 처럼.

### 모의계산 라벨은 항상 보여야 한다

`SRS-FR-082` — **스크롤해도 sticky로 고정**된다. 실제 인출로 오해되면 안 된다.

---

## 계산은 표현 계층에서 하지 않는다

| 계층 | 금지 사항 |
| --- | --- |
| 표현 (Server/Client Component) | **밴드·세액 계산 금지** |

**병목 종목 지목은 서버가 한다** (`SRS-FR-019`). 클라이언트는 결과만 받아 표시한다.

> **예외 하나** — F2-03·F2-04는 인출액 재계산을 클라이언트에서 한다 (§9.3, p95 300ms 요구). 단 **제출·저장 시점에는 서버 계산 결과만 사용**하고 (`TEC-CALC-003`), **세율 신선도 판정은 서버 전용**이다 (`TEC-CALC-004`).

## 컴포넌트 매핑 — §6.1 확정

| 화면 요소 | shadcn/ui |
| --- | --- |
| 진행 카드 | `Card` |
| 단계 타임라인 | `Progress` + 커스텀 |
| 제한 업무 표 | `Table` |
| 종목 3그룹 판정 | `Accordion` + `Badge` |
| 고객센터 연결 | `Sheet` |
| 계산 근거 토글 | `Collapsible` |
| 한도 게이지 | `Progress` (3구간 커스텀) |
| 인출액 입력 | `Input` + `Slider` |
| 인출 사유 선택 | `Select` |
| 3층 소진 시각화 | 커스텀 (Tailwind) |
| 경고·주의 | `Alert` |
| 전송 확인 | `AlertDialog` |
| 약관 전문 | `ScrollArea` |
| 예외 상태 배너 | `Alert` (variant) |

**색·간격을 임의값으로 쓰지 않는다.** Tailwind 토큰에서만 가져온다 — C-TEC-004의 목적이 일관성 강제다.

## 위반을 발견했을 때

1. 날짜를 `<BandDisplay>` 없이 렌더하려 하면 → **멈춘다**
2. enum을 직접 출력하려 하면 → `<StatusLabel>`로 바꾼다
3. 금액 없이 비율만 보여주려 하면 → 금액을 병기한다
4. 문구를 생성하려 하면 → **매핑표를 찾거나 사람에게 확인**
5. ARIA·포커스 표시를 제거하려 하면 → **멈춘다**
