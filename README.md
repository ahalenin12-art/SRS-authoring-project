# SRS 제작 프로젝트

KB증권 연금 서비스 기획 산출물을 **예시 SRS(`AD-Core-Platform`) 양식**의 소프트웨어 요구사항 명세서로 변환하는 프로젝트입니다.

---

## 작업 목표

이 프로젝트의 목표는 **표준 SRS 규격에 맞는 풀 버전 문서를 작성하는 것이 아닙니다.**

1. **목표는 포맷 이식입니다.** 예시 SRS 문서와 같은 포맷으로 변환합니다. 목차 구성, 섹션 순서, 서술 방식, 표기 규칙을 그대로 따릅니다.
2. **예외는 범위를 벗어나는 내용뿐입니다.** 원본에 예시 SRS의 범위를 벗어나는 내용이 있는 경우에 한해, SRS 표준 포맷 구성에 따라 **해당 부분만** 확장합니다.
3. **확장은 최소로 합니다.** 예시 범위 안에서 처리 가능한 내용을 임의 확장하지 않습니다. 예시에는 있으나 원본에 대응 내용이 없는 섹션은 만들지 않습니다.

## 미해결 사항

착수 전에 닫아야 하는 항목입니다. 전부 SRS §6.14.2에 대응책이 걸려 있어 답이 늦어져도 축소형으로 인도됩니다.

| 항목 | 등급 | 미확보 시 |
| --- | :---: | --- |
| `settle_days` 실측 확보 (SYS-Q3) | **게이트** | Phase 1 착수 불가 |
| 콜센터 문의코드 `TRF-STATUS` 신설 (SYS-Q7) | **게이트** | 기준선 없이 Phase 1 승격 불가 |
| 투자자문업 해당 여부 판정 (LEGAL-Q1) | **게이트** | **기능2 출시 보류.** 기능1은 단독 출시 가능 |
| 밴드 검증 기준값 확정 | 축소 | 밴드 검증값을 인수 판정에서 제외 (§6.15.5) |
| 라목 잔액 분리 관리 | 축소 | 1,500만원 판정 게이지 비노출 |
| 예약 접수 규정 충돌 | 축소 | 예약을 저장 전용으로 축소 |
