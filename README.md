# SRS 제작 프로젝트

KB증권 연금 통합 시연 프로토타입(V7)을 SRS(Software Requirements Specification) 문서로 변환하는 프로젝트입니다.

---

## 작업 목표

이 프로젝트의 목표는 **표준 SRS 규격에 맞는 풀 버전 문서를 작성하는 것이 아닙니다.**

1. **목표는 포맷 이식입니다.** 예시 사례로 넣어둔 SRS 문서와 같은 포맷의 문서로 변환하는 것이 목표입니다. 예시 SRS 문서의 목차 구성, 섹션 순서, 서술 방식, 표기 규칙을 그대로 따릅니다.

2. **예외는 범위를 벗어나는 내용뿐입니다.** 원본 문서에 예시 SRS 문서의 범위를 벗어나는 내용이 있는 경우에 한해, SRS 표준 포맷의 구성에 따라 **해당 부분만** 확장해서 작성합니다.

3. **확장은 최소로 합니다.** 예시 SRS의 범위 안에서 처리 가능한 내용을 표준 포맷 기준으로 임의 확장하지 않습니다. 예시 SRS에는 있지만 원본에 대응 내용이 없는 섹션은 만들어내지 않습니다.

### 변환 규칙

| 원본 내용의 성격 | 처리 방식 |
| --- | --- |
| 예시 SRS에 대응 섹션이 있음 | 예시 SRS 포맷 그대로 변환 |
| 예시 SRS의 범위를 벗어남 | SRS 표준 포맷 구성에 따라 해당 부분만 확장 작성 |
| 예시 SRS에는 있으나 원본에 근거 없음 | 생성하지 않음 |
