## 계산 재현

일정·의존성 수치는 **손으로 유추하지 않았습니다.** 태스크 리스트를 파싱해 계산한 값이며, 스크립트를 함께 보관합니다.

```bash
node tools/dag.mjs      # 웨이브 · 임계 경로 · 병목 · Epic별 공수
node tools/sched.mjs    # 편성안별 기간 · 가동률 · 주차 배치
node tools/blocked.mjs  # 차단 태스크 답변 기한
node tools/deps.mjs     # 선행 · 후행 재생성
node tools/cmp.mjs      # 전체판 · 병합판 비교
```

소요 모델 `L=1일 · M=3일 · H=6일`은 **가정**입니다. 팀 실측 속도가 확보되면 각 스크립트의 `DUR` 상수를 교체하고 전 문서를 재계산해야 합니다.

## 작업 원칙

이 저장소의 문서들이 지킨 규칙입니다.

1. **근거 없는 내용을 만들지 않는다.** 상위 문서에 없는 기능·요구사항을 태스크로 만들지 않았습니다. 적합성 평가에서 결함 3건을 찾았지만 **SRS 근거가 있는 1건만 태스크로 추가**하고 2건은 소관 문서로 이관했습니다.
2. **못 정하는 것을 정한 척하지 않는다.** 미해결 항목은 TBD로 남기고 **누가 언제까지 답해야 하는지**를 명시했습니다.
3. **기술 선택의 대가를 숨기지 않는다.** 제약 충돌 7건을 별도 장으로 격리하고 완화 가능 여부와 잔여 위험을 나눠 적었습니다.
4. **수치는 계산하고 재현 가능하게 남긴다.** 임계 경로·편성안·답변 기한은 전부 스크립트 산출값입니다.
