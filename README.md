# SRS 제작 프로젝트

KB증권 연금 통합 시연 프로토타입(V7)을 SRS(Software Requirements Specification) 문서로 변환하는 프로젝트입니다.

---

## 작업 목표

이 프로젝트의 목표는 **표준 SRS 규격에 맞는 풀 버전 문서를 작성하는 것이 아닙니다.**

1. **목표는 포맷 이식입니다.** 예시 사례로 넣어둔 SRS 문서와 같은 포맷의 문서로 변환하는 것이 목표입니다. 예시 SRS 문서의 목차 구성, 섹션 순서, 서술 방식, 표기 규칙을 그대로 따릅니다.

2. **예외는 범위를 벗어나는 내용뿐입니다.** 원본 문서에 예시 SRS 문서의 범위를 벗어나는 내용이 있는 경우에 한해, SRS 표준 포맷의 구성에 따라 **해당 부분만** 확장해서 작성합니다.

3. **확장은 최소로 합니다.** 예시 SRS의 범위 안에서 처리 가능한 내용을 표준 포맷 기준으로 임의 확장하지 않습니다. 예시 SRS에는 있지만 원본에 대응 내용이 없는 섹션은 만들어내지 않습니다.

### 변환 규칙

| 원본 내용의 성격 | 처리 방식 |
| --- | --- |
| 예시 SRS에 대응 섹션이 있음 | 예시 SRS 포맷 그대로 변환 |
| 예시 SRS의 범위를 벗어남 | SRS 표준 포맷 구성에 따라 해당 부분만 확장 작성 |
| 예시 SRS에는 있으나 원본에 근거 없음 | 생성하지 않음 |

## 입력 자료

### 확보됨

| 파일 | 설명 |
| --- | --- |
| `source/통합_프로토타입_최종_V7.html` | KB증권 연금 통합 시연 프로토타입 V7. 모바일(375×812) 단일 HTML 프로토타입, 8개 화면 구성. 원본 그대로이며 수정하지 않음 |
| `source/통합_프로토타입_최종_V7.md` | 위 HTML의 내용을 손실 없이 옮긴 Markdown 변환본. 화면별 문구·수치·버튼 동작, 상태 전이 로직, 캘린더 데이터, 디자인 토큰 포함. 원본의 내부 불일치 6건은 본문에서 고치지 않고 부록 C에 별도 기록 |

프로토타입에 포함된 화면:

- `screen-menu` — 연금 메뉴 진입
- `screen-manage` — 입금 관리 / 출금 관리
- `screen-f1-0` ~ `screen-f1-3` — 기능1: 이수관(계좌이체) 진행 흐름 및 현황판
- `screen-f2-entry`, `screen-f2-detail` — 기능2: 인출순서·세금 시뮬레이터

### 미확보

| 항목 | 필요한 이유 |
| --- | --- |
| **예시 SRS 문서** | 변환 목표 포맷을 정의하는 기준 문서. 이 문서 없이는 "예시와 같은 포맷"이 무엇인지 확정할 수 없으므로 변환 착수 불가 |

원본 기획 문서(PID)가 추가로 제공될 경우 해당 문서를 1차 원본으로 삼고, 프로토타입은 화면·상태 근거 자료로 사용합니다.
