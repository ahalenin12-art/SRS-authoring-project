# Epic `TST` — Verification

근거: [적합성 평가 D-02 재판정](../07_%5B%EB%B6%84%EC%84%9D%5D%20%ED%83%9C%EC%8A%A4%ED%81%AC%20%EC%B6%94%EC%B6%9C%20%EB%B0%A9%EB%B2%95%EB%A1%A0%20%EC%A0%81%ED%95%A9%EC%84%B1%20%ED%8F%89%EA%B0%80%20%28%EC%97%B0%EA%B8%88%ED%94%8C%EB%9F%AC%EC%8A%A4%29.md) · PRD v3.1 §5 · §8.6 · §8.7

> **이 Epic은 D-02 재판정으로 추가되었다.** 최초 적합성 평가는 "SRS-002에 시험 요구가 없다"며 이관 처리했으나, **PRD §8.6~8.7에 검증 대상이 명시되어 있었다.** 원래 판정이 SRS-002만 근거로 삼은 오류였다.
>
> 이 Epic 추가로 **임계 경로가 39일 → 45일로 6일 늘었다.** 다만 39일은 시험을 세지 않은 숫자였다. **45일이 정직한 값이다.**

## 이미 다른 태스크가 덮는 것 — 중복하지 않는다

| 검증 대상 | 담당 |
| --- | --- |
| 검증 데이터셋 6건 원 단위 일치 | `FR-016` (도메인 단위 시험 + 배포 게이트) |
| 상태 전이 판정 **로직** (순수 함수) | `FR-013` DoD — 21건 시험 케이스 |
| 성능 SLO p95 5종 실측 | `FR-050` |
| 개별 기능의 정상·실패 흐름 | 각 태스크의 Acceptance Criteria |

**이 Epic은 그 위의 층을 다룬다** — 요구사항 추적, 통합 수준 전이, 예외 계열 전건 대응, 사용자 여정.
