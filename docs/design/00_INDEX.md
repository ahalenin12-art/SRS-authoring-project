## 읽는 순서

목적에 따라 다릅니다.

**처음 접하는 사람** — 무슨 서비스인지부터

```
01 유스케이스 → 07 FC-08 이관 전체 여정 → 06 상태 다이어그램
```

**개발 착수** — 만들 것부터

```
04 컴포넌트 → 03 클래스 → 02 ERD → 05 시퀀스
```

**법정 계산 구현** — 산식이 헷갈릴 때

```
07 FC-01 한도 → FC-02 3층 차감 → FC-03 4버킷 → FC-04 부득이한 사유
```

**QA · 검증 설계** — 무엇을 어떻게 시험할지

```
05 시퀀스 (각 SD가 인수 조건과 1:1) → 06 상태 전이 → SRS §6.7.2
```

**기획 · 사업 판단** — 왜 이렇게 만들었는지

```
08 인과 순환 → SRS §6.12 (ADR) → SRS §6.15.1 (사업 배경)
```

## 설계를 지배하는 4개 제약

모든 문서가 아래 제약 위에 서 있습니다. 설계 판단이 갈릴 때 여기로 돌아옵니다.

| # | 제약 | 어디에 나타나는가 |
|:---:|---|---|
| **L-1** | 이관사 내부 진행(③④)에 실시간 조회 경로가 **없다** | ERD의 `layer`/`confidence` · 상태도의 추정 구간 · FC-06 폴백 사다리 |
| **L-2** | 마이데이터에 재원 구분 항목이 **없다** | ERD §4 · 클래스 `guardForeignAccount()` · SD-07 타사 분기 |
| **L-4** | 매매 제한 범위·시점을 **이관사가 정한다** | `trading_window` 분리 · D-4 보수 강등 · FC-07 |
| **L-6** | 종목·수량·시기를 지정하면 **투자자문업**이 된다 | `is_simulation_only` · 결과 화면에 실행 버튼 없음 · ADR-006 |

## 미해결 사항

설계 확정 전에 닫아야 하는 항목입니다. 전부 SRS §6.14.2에 대응책이 걸려 있어 답이 늦어져도 축소형으로 인도됩니다.

| 항목 | 영향 받는 설계 | 미확보 시 |
|---|---|---|
| `settle_days` 실측 확보 | FC-06 폴백 사다리 · `SETTLE_DAYS_DICT` | **Phase 1 착수 불가 (게이트)** |
| 콜센터 문의코드 신설 | 08 인과 순환의 북극성 측정 | **기준선 없이 Phase 1 승격 불가 (게이트)** |
| 라목 잔액 분리 관리 | FC-05 · `FundSourceBalance.itemRaSeparated` | 판정 게이지 비노출 |
| 예약 접수 규정 충돌 | 06 상태도의 `DRAFT` · ADR-002 | 저장 전용으로 축소 |
| 밴드 검증 기준값 | SRS §6.7.3 · §6.15.5 | 밴드 검증값을 인수 판정에서 제외 |
