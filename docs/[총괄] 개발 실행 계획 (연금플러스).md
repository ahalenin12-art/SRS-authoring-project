## 0. 이 문서의 위치

SRS-002는 **무엇을 어떻게 만드는가**까지 확정했다. 태스크 리스트는 그것을 **작업 단위**로 갈랐다. 이 문서는 그 작업들을 **어떤 순서로, 누가, 언제** 하는가를 정한다.

**이 문서가 하지 않는 것.** 요구사항 결정, 기술 선택, 미해결 항목의 답. 그것들은 상위 문서 소관이고, 여기서는 **답이 언제까지 필요한지**만 계산한다.

**모든 수치는 재현 가능하다.** 의존 그래프·임계 경로·편성안은 [tools/](../tools/)의 스크립트가 태스크 리스트를 직접 파싱해 계산한 값이다. 손으로 유추한 숫자가 아니다.

## 1. 실행 전략

### 1.1 네 가지 원칙

**① 차단된 것이 나머지를 세우지 않는다.**
미해결 5건에 걸린 태스크는 8건뿐이고, **59건은 지금 착수할 수 있다**(§2.4). 답을 기다리며 전체를 멈추는 것은 근거 없는 손실이다.

**② 임계 경로 위 태스크는 인원을 늘려서라도 먼저 끝낸다.**
임계 경로 8단계는 전부 백엔드 사슬이다. 이 위의 하루 지연이 곧 전체 하루 지연이다. 경로 밖 지연은 흡수된다.

**③ 계산 로직은 첫 주에 끝낸다.**
도메인 모듈(FR-008~016)은 선행이 FR-001 하나뿐이고 I/O가 없어 **DB·화면 없이 검증된다**. 가장 먼저 끝나야 뒤의 모든 것이 이 위에서 조립된다.

**④ 규칙은 도구로 강제하고 사람에게 맡기지 않는다.**
FR-006(DB 제약) · FR-035(표기 컴포넌트 타입) · FR-036(ESLint 룰)은 기능이 아니라 **위반 차단 장치**다. 늦게 넣으면 이미 위반한 코드를 고쳐야 한다. 해당 계층의 첫 태스크와 함께 넣는다.

착수 예정일이 곧 답변 기한이다. 표준안(57일) 기준.

| 미해결 | 차단 태스크 | 착수 예정 | **답변 기한** | 에스컬레이션 |
| --- | --- | :---: | :---: | :---: |
| OPEN-TEC-001/002 Cron 주기 | FR-033 | D+22 | **D+22** | D+17 |
| OPEN-TEC-004 전문 수신 경로 | FR-028 | D+34 | **D+34** | D+29 |
| OPEN-TEC-007 본인 인증 수단 | FR-022 | D+34 | **D+34** | D+29 |
| OPEN-TEC-004 (어댑터) | FR-018 | D+46 | D+46 | D+41 |
| OPEN-TEC-001/002 (정합성) | FR-032 | D+40 | D+40 | D+35 |

**가장 이른 기한은 D+22(Cron 주기)다.** 착수 첫날 요청하면 4주 반의 여유가 있다. 이 표를 그대로 각 소관 부서에 전달한다.

## 5. 진척 추적

### 5.1 무엇을 보는가

| 지표 | 주기 | 판정 |
| --- | --- | --- |
| **임계 경로 8건 상태** | 매일 | 1건이라도 지연 → 전체 지연 확정 |
| 웨이브 전환 가능 여부 | 주 1회 | 다음 웨이브 선행이 전부 닫혔는가 |
| 차단 태스크 답변 잔여일 | 주 1회 | 기한 −5일 도달 시 에스컬레이션 |
| G1 검증 데이터셋 통과율 | 계산 모듈 완료 시마다 | 6건 전건 일치 아니면 미통과 |
| 완료 태스크 수 / 67 | 주 1회 | 참고용. **임계 경로가 우선 지표** |

> **"완료 67건 중 몇 건"은 주 지표가 아니다.** 경로 밖 태스크 10건을 끝내도 일정은 안 당겨진다. 임계 경로 1건이 더 중요하다.

### 5.2 운영 리듬

| 시점 | 활동 |
| --- | --- |
| 매일 15분 | 임계 경로 8건 + 차단 태스크 5건만 확인 |
| 주 1회 | 웨이브 전환 점검 · 답변 기한 갱신 |
| 웨이브 종료 시 | 다음 웨이브 인원 재배치 |
| 3스프린트 후 | **소요 상수 실측 교체 + 전 일정 재계산** |

### 5.3 계획 갱신

이 문서의 숫자는 태스크 리스트에서 자동 산출된다. 태스크가 바뀌면 문서를 고치지 말고 **재계산한다.**

```bash
node tools/dag.mjs      # 웨이브 · 임계 경로 · 병목
node tools/sched.mjs    # 편성안별 기간 · 주차 배치
node tools/blocked.mjs  # 차단 태스크 답변 기한
```
